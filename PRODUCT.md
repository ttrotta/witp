# WITP

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
People recording where they experience physical pain and reviewing their own history.

## Product Purpose
Select a body region on an interactive human model and record pain intensity, notes, and date.

## Capabilities and Constraints
Next.js 16, React 19, R3F, Zustand 5, Prisma/PostgreSQL, and Tailwind 4. English and Spanish. Independent anatomy and pain modules compose through shared state at the route. Authentication uses the existing User model, as confirmed by the user. Work and verification remain inside WSL.

## Brand Commitments
The name is witp. The user requests frosted glass panels, a floating capsule navigation, and an immediately interactive anatomical Home.

## Evidence on Hand
The database schema exists. No anatomical asset or authentication implementation was supplied. Generated geometry is a body-region locator, not a diagnostic model.
