## 2026-10-05 - Initial Project Scaffold & Screaming Architecture Foundations

### Context & Session Goal
Bootstrap the core technical foundation of WITP as a modular, 3D-interactive pain tracking platform using Next.js 16 (App Router), React 19, Tailwind CSS v4, and Prisma ORM v7.

### Key Architectural Decisions
- **Screaming Architecture**: Established strict layer boundaries:
  - `src/app`: Routing and layout orchestration.
  - `src/modules`: Domain logic (`anatomy-3d`, `auth`, `pain-tracking`, `community`, `user-profile`, `waitlist`).
  - `src/shared`: Reusable UI primitives, Zustand stores, anatomical constants.
  - `src/infrastructure`: Database, auth primitives, internationalization.
  - `src/ai`: Model Context Protocol (MCP) and agent workflows.
- **Prisma ORM v7 & PostgreSQL**: Adopted Prisma ORM v7 with `@prisma/adapter-pg` driver adapter and output generation configured to `../generated/prisma`.
- **Draco-Compressed 3D Human Model Pipeline**: Built procedural 3D model generator (`generate-model.ts`) utilizing `@gltf-transform` and Google Draco compression (`draco3dgltf`), compressing human anatomy mesh representations down to $< 2\text{ MB}$.
- **Anatomical Contract**: Defined `src/shared/anatomy.ts` exporting canonical `bodyParts` with 3D coordinates and `meshId` keys, establishing the contract between 3D assets, database models, and UI state.
- **Runtime Validation**: Selected Zod 4 for input and payload validation.

### Modified & Created Files
- `package.json`: Defined dependencies (`@react-three/fiber`, `@react-three/drei`, `three`, `prisma`, `@prisma/adapter-pg`, `zod`, `zustand`, `lucide-react`).
- `tsconfig.json`: Configured strict path aliases (`@/*` -> `src/*`, `@generated/*` -> `generated/*`).
- `prisma.config.ts`: Prisma v7 configuration file.
- `prisma/schema.prisma`: Initial database entities (`User`, `Session`, `BodyPart`, `PainRecord`, `WaitlistEmail`).
- `src/shared/anatomy.ts`: Canonical 32 anatomical landmarks and type definitions.
- `src/modules/anatomy-3d/generate-model.ts`: Procedural geometry generator.
- `public/models/anatomy.glb`: Generated Draco-compressed 3D mesh model.
- `public/draco/draco_decoder.wasm`: WebAssembly decoder binary.
- `witp.test.ts`: Automated test suite for Draco mesh validation and validation contracts.

## 2026-10-08 - 3D Anatomy Interaction, Session Auth, and Pain Tracking MVP

### Context & Session Goal
Deliver the interactive MVP for 3D body region selection, pain severity logging, and user authentication.

### Key Architectural Decisions
- **R3F Pointer Picking & Material Highlighting**:
  - Attached pointer handlers to individual body region meshes in `HumanModel.tsx`.
  - Added a drag threshold check (`event.delta <= 4`) to distinguish OrbitControls camera rotation from mesh selection clicks.
  - Configured three material states: default `#b4c9c7`, hover highlight `#b6eadf` (emissive `#40bc9a`), and active selection `#7ce9cc`.
- **Cross-Layer Zustand Coordination**:
  - Implemented `useAnatomyStore` in `src/shared/store/` to synchronize `selectedMeshId`, `hoveredMeshId`, and `cameraTarget` between the R3F canvas and DOM pain tracking inputs without cross-module coupling.
- **Cryptographic Session Authentication**:
  - Implemented session persistence in PostgreSQL with token hashing (`SHA-256`) and secure cookie storage (`witp-session`, `HttpOnly`, `SameSite=Lax`).
  - Implemented secure password hashing via Node.js native `crypto.scrypt` with random salting.
  - Added sliding-window rate limiting to auth actions (max 8 attempts per 15 minutes).
- **Server Actions RPC Standard**:
  - Replaced REST `/api` routes with typed Next.js Server Actions returning `{ success: true, data } | { error: string }`.

### Modified & Created Files
- `src/modules/anatomy-3d/components/HumanModel.tsx`: 3D human model mesh component with pointer picking.
- `src/modules/anatomy-3d/components/AnatomyCanvas.tsx`: R3F Canvas container with demand rendering.
- `src/modules/anatomy-3d/components/AnatomyScene.tsx`: Lighting and camera scene graph.
- `src/modules/anatomy-3d/components/ViewportControls.tsx`: Smooth camera framing via OrbitControls.
- `src/shared/store/useAnatomyStore.ts`: Global state store for anatomical selection.
- `src/infrastructure/auth/session.ts`: Session tokens, cookies, and active session query.
- `src/infrastructure/auth/password.ts`: Scrypt hashing and constant-time verification.
- `src/infrastructure/auth/rate-limit.ts`: In-memory sliding-window limiter.
- `src/modules/auth/actions.ts`: `authenticate` and `signOut` Server Actions.
- `src/modules/auth/schemas.ts`: Zod schema for registration and login.
- `src/modules/pain-tracking/actions.ts`: `createPainRecord` and `getPainHistory` actions.
- `src/modules/pain-tracking/schemas.ts`: `painRecordSchema` validation.
- `src/modules/waitlist/actions.ts`: `subscribeToWaitlist` action.
- `src/modules/waitlist/schemas.ts`: `waitlistSchema` validation.
- `witp.test.ts`: Added tests for auth attempts, password verification, and pain validation boundaries.
