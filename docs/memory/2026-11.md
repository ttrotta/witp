## 2026-11-02 - Documentation Audit Against the Code

### Context & Session Goal
Audit the canonical documentation in PR #2 against the code, then close the gaps that do not depend on the database. Database work was explicitly deferred: `prisma/`, `docs/DATABASE.md` and `docs/database/SCHEMA.md` were left untouched.

### Key Architectural Decisions
- **REST is a target contract, not a current interface**: `docs/ARCHITECTURE.md` rejected REST while `docs/API.md` marked it as implemented. Server Actions are the only interface today. REST stays specified for external clients and is marked `[ROADMAP]` per route.
- **Locale proxy matcher**: `src/proxy.ts` must export a literal `config`. It exported `i18nConfig`, so Next.js ignored the matcher and redirected `/api/*` to a locale prefix.
- **Waitlist error codes**: `subscribeToWaitlist` now returns stable codes (`invalid`, `duplicate`, `rateLimited`, `connection`) so the UI can translate them, and it is limited to 5 attempts per 10 minutes per IP.
- **Fixed-window limiter**: the limiter was documented as a sliding window. The documents now describe what it does. The rate limit is per process.
- **Layer boundaries in lint**: the dependency matrix is enforced by `no-restricted-imports`. `shared` may import `infrastructure/i18n` because `Navbar` needs translations.
- **Coming-soon pages**: forum, post, blog and profile rendered bare placeholder text. They now share `ComingSoon` and offer the waitlist form.
