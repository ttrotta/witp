# WITP body map

`anatomy.glb` is original procedural geometry generated by `src/modules/anatomy-3d/generate-model.ts` for this project. It uses no external anatomical asset or texture. It represents surface regions for a personal pain journal, not clinical anatomy or diagnosis.

Run `pnpm model:generate` to reproduce it. The 32 mesh and node names match `src/shared/anatomy.ts` and `prisma/seed.ts`. Left/right refer to the subject's anatomical left/right, not the viewer's screen.

Compression: KHR_draco_mesh_compression; 14-bit position and 10-bit normal quantization. Local decoders live in `/draco/`.
